# Day 12 Task - Student Registration System (Flask + SQLite)

## Objective

Transform your Student Registration System from a frontend prototype into a fully functional web application using Flask and SQLite.

---

## Task Requirements

### Database Integration

* Create and connect an SQLite database.
* Create a `Students` table with appropriate fields.
* Establish database connection using Python.
* Verify successful database creation and connectivity.

### Form Integration

Connect the Student Registration Form with the Flask backend.

The form should collect and store:

* Student Name
* Roll Number
* Department
* Year
* Email
* Phone Number
* Gender
* Address

### Data Storage

* Accept form data using POST requests.
* Insert student records into the SQLite database.
* Display success messages after successful registration.
* Validate that records are stored correctly.

### Students List Page

* Retrieve data directly from SQLite.
* Display records dynamically using Flask templates.
* Show all registered students in a formatted HTML table.

### Flask Backend Requirements

Implement:

* Database connection
* Table creation
* Data insertion
* Data retrieval
* Route handling
* Form processing

---

## Testing Requirements

After implementation:

* Register at least 10 students using the web form.
* Verify records are stored in SQLite.
* Verify records are displayed on the Students page.
* Ensure no errors occur during insertion or retrieval.
* Test navigation between all pages.
* Test form submission multiple times.

---

## Deliverables

* SQLite database created.
* Flask connected to SQLite successfully.
* Registration form storing real data.
* Students page displaying database records.
* Fully functional Student Registration System.
* Screenshots of:

  * Registration form submission
  * Database records
  * Students list page

---

# Final Project Development

After successfully completing the Student Registration System:

Each team must begin implementing the same Flask architecture and development workflow for their assigned internship project.

## Final Project Requirements

Your final project must include:

* Flask Routing
* HTML Templates
* CSS Styling
* SQLite Database Integration
* Dynamic Data Storage
* Dynamic Data Display
* Professional User Interface

## Goal

Use the Student Registration System as a reference implementation and apply the same concepts to your assigned project.

The final project should follow a complete Flask workflow:

```text
HTML Form
    ↓
Flask Backend
    ↓
SQLite Database
    ↓
Dynamic Data Retrieval
    ↓
HTML Template Rendering
```

Ensure that your assigned project has a functional backend, connected database, and a professional user interface.
