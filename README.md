# Innoloft Ventures — 20-Day Internship Program

## Welcome to VEL TECH Training Repository

This is the central repository for the **Innoloft Ventures 20-day internship program** at **Vel Tech Rangarajan Dr. Sagunthala R&D Institute of Science and Technology, Chennai**.

Every student in this program will build a **live deployed AI-powered web application** over 20 days of hands-on training across 4 progressive tracks.

---

## 🎯 Program Overview

**What?** A 20-day intensive internship program in AI, Machine Learning, and Web Development.

**Who?** 17 engineering students from Vel Tech University, mentored by 4 industry professionals from Innoloft Ventures.

**Outcome?** Each student walks away with:
- ✅ A live deployed AI web application with a public URL
- ✅ A GitHub portfolio with 20 days of consistent commits
- ✅ Internship completion certificate from Innoloft Ventures
- ✅ LinkedIn-ready project showcase
- ✅ Real hands-on industry experience

## 📚 4-Track Structure

### **Track 1 — Python + ML Basics (Days 1–5)**
**Led by Jayasri**

Build your Python foundation and create your first ML model.

**Topics:**
- Python fundamentals (variables, loops, functions)
- NumPy and Pandas for data handling
- Exploratory Data Analysis (EDA)
- Building your first ML model with scikit-learn

**Deliverable:** Trained ML model saved as `.pkl` file pushed to GitHub

**Repository Structure:**
```
Day 1/
├── bmi_calculator/
└── first_script.py
Day 2/
├── num_guess.py
└── how to write readme file and github commands.md
Day 3-5/
└── [Daily assignments and models]
```

---

### **Track 2 — Advanced Machine Learning (Days 6–10)**
**Led by Akhil**

Deepen your ML skills with advanced algorithms and optimization techniques.

**Topics:**
- Comparing multiple algorithms (Random Forest, Gradient Boosting, KNN, SVM)
- Hyperparameter tuning using GridSearchCV
- CNN basics using MNIST dataset
- Data visualization with Seaborn and Power BI

**Deliverable:** Improved ML model with comparison results and visualizations

**Repository Structure:**
```
Day 6-10/
├── algorithm_comparison/
├── hyperparameter_tuning/
├── cnn_basics/
└── visualization_results/
```

---

### **Track 3 — Web Development (Days 11–15)**
**Led by Balakrishnan**

Build a complete web interface to connect with your ML model.

**Topics:**
- HTML & CSS fundamentals
- Flask routing and web server basics
- Jinja2 templates
- HTML forms and user input handling
- SQLite database integration
- JavaScript basics for interactivity

**Deliverable:** Complete Flask web application with multiple pages and forms

**Repository Structure:**
```
Day 11-15/

│   └── results.html

```

---

### **Track 4 — Final Project + Deployment (Days 16–20)**
**Led by Venkatesh**

Bring everything together and deploy your AI web application live.

**Topics:**
- Connecting ML model to Flask web app
- UI/UX polishing and optimization
- Error handling and edge cases
- Deployment to free hosting (Render or Railway)
- Live public URL generation
- Demo Day presentation

**Deliverable:** Live deployed AI web application accessible on the internet

**Day 19:** Final rehearsal and presentation practice  
**Day 20:** Demo Day — Present to panel, viva, and certificate ceremony

## 🛠️ How to Use This Repository

**For Students:**
1. Navigate to your current day's folder
2. Complete the assignments given by your mentor
3. Test your code locally
4. Stage and commit your changes:
   ```bash
   git add .
   git commit -m "Day X: Brief description of what you did"
   git push
   ```
5. Submit your daily report on InnoTrack before 5:00 PM

**GitHub Commands Quick Reference:**
```bash
# View commit history
git log --oneline

# Check status
git status

# Push changes
git push

# Pull latest changes
git pull
```

**For more detailed GitHub commands:** See `Day 2/how to write readme file and github commands.md`
